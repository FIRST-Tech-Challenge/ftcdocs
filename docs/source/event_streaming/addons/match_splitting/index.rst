Match Splitting
===============

A recording of a full event day is eight or more hours long. Teams looking for
their own :term:`matches <Match>`, whether to review them or to scout the teams they'll face
next, have to scrub through all of it. Match splitting turns the day into one
short video per match, or adds chapter markers to the full
recording so each match is one click away.

There are two ways to do this:

- :doc:`Live <live/live>`: an automation tool starts and stops a recording
  for each match as it happens. This needs the Gold-tier
  :doc:`FTC Live integration </event_streaming/addons/ftc_live_integration/ftc-live-integration>`.
- :doc:`Post-event <post_event/post-event>`: a volunteer cuts the day's
  recording into matches after the event. This works at any tier, and needs
  only the recording and the match schedule.

Splitting matches live without automation means someone has to start and stop
a recording for every match, which ties up a :term:`volunteer <Volunteer>` for the whole event.
Bronze and Silver events should split matches after the event instead.
