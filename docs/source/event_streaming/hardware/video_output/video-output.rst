Video Output
============

Once the stream is running, it is often the best view of the field in the
building: it is framed, shows the score, and doesn't have someone's head in
the way. Consider sending OBS's program output to the venue's projector as the
main audience display.

This also helps the stream. When the audience is watching the same picture
that viewers at home see, a camera that gets bumped or a view that is blocked
by field staff gets noticed and fixed within minutes instead of hours.

Showing the Program Output
--------------------------

Use OBS's fullscreen projector feature to send the program output to the
projector as a second display. The projector then shows exactly what is being
streamed, with almost no delay.

Don't put the YouTube stream itself on the projector. YouTube adds several
seconds of delay, so the audience would see each :term:`match <Match>` end after it has
already ended in the room.

Getting the Signal to the Projector
-----------------------------------

For short distances, a standard HDMI cable works. For longer runs, there are
two common options.

**Fiber optic HDMI cables**

These carry HDMI over fiber inside an ordinary-looking cable. They don't need
extra power or adapter boxes, and 100 and 150 foot cables (about $42) have
been reliable across many venues and projectors.

- Fiber HDMI cables are directional. Connect the end labeled *Source* to the
  computer and the end labeled *Display* to the projector.
- The fiber can break if the cable is kinked, bent tightly, stepped on, or
  rolled over by a cart. Route it along walls or under cable covers, and coil
  it loosely.

**HDMI over Ethernet (HDBaseT)**

These use a transmitter and receiver at each end of a network cable (about
$40 for short-range kits and $100 for longer-range kits). They are useful
when a network cable is already run through a wall or ceiling. Both ends need
power, and some volunteers have found them less reliable than fiber HDMI.

Gold Tier: Displays Anywhere on the Network
-------------------------------------------

At championships, OBS can send its program output over the network as an NDI
source. An NDI decoder box (about $170) connected to any display on the same
network can then show the program feed. This is useful for putting the
audience display in a pit area on the other side of the building, without
running an HDMI cable there.
