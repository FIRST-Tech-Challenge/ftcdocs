Streaming Platform
==================

YouTube is the recommended platform for FTC event streams. Choosing a
platform doesn't depend on tier; make the decision once and use the same
channel for every event.

Why YouTube
-----------

The biggest practical difference between platforms is what happens when
copyrighted music ends up on the stream, which is hard to prevent completely
at a live event:

- **YouTube** mutes or blocks the affected part of the stream, and the stream
  keeps going.
- **Twitch** can suspend the channel, which stops the stream in the middle of
  the event.

For that reason, don't use Twitch for event streams.

Some schools block youtube.com for viewing, but this usually doesn't stop an
event from streaming *to* YouTube. See
:doc:`Network </event_streaming/hardware/network/network>`.

Setting Up the Channel
----------------------

Set up the channel at least a week before the first event.

- Use a channel owned by the program or region, not a :term:`volunteer's <Volunteer>` personal
  account, so it doesn't disappear when a volunteer moves on. Give at least
  two people manager access.
- Enable live streaming on the channel. The first time live streaming is
  enabled, YouTube can take up to 24 hours to turn it on.
- Schedule each event's stream in advance in YouTube Studio. A scheduled
  stream has a link you can share with teams before the event.
- Use a persistent stream key so the same key works in OBS at every event.
  Treat the key like a password; anyone who has it can stream to the
  channel.

Chat and Comments
-----------------

Viewers on an FTC stream include students. Either turn off live chat, or
assign a moderator to watch it for the whole event. An unmoderated chat on a
public youth event stream is a risk that isn't worth taking.

Long Events
-----------

YouTube doesn't keep an archive of livestreams longer than 12 hours. For long
days, or multi-day events, end the stream and start a new one at a natural
break, such as lunch or the end of each day.
