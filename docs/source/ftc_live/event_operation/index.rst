FTC Live Event Operation
========================

These pages cover running the event on event day, after FTC Live is installed
and the event is prepared. Complete the
:doc:`FTC Live Setup Guide </ftc_live/setup/index>` first. Work through the pages in
this order:

#. :doc:`Match Control </ftc_live/event_operation/match_control/match-control>`: run test,
   practice, and qualification matches.
#. :doc:`Alliance Selection and Playoffs </ftc_live/event_operation/alliance_selection_and_playoffs/alliance-selection-and-playoffs>`:
   run alliance selection and the playoff matches.
#. :doc:`Awards </ftc_live/event_operation/awards/awards>`: enter and present awards.
#. :doc:`After the Event </ftc_live/event_operation/after_the_event/after-the-event>`: print
   the advancement report, send results, and manage the server.
