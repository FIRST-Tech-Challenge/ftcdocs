FTC Live Setup Guide
====================

*FIRST*\ ® Tech Challenge event management is split across three systems: the
cloud-based *FIRST* Event Portal, the local software that runs on event day
(FTC Live), and a public website. This guide covers the system requirements
and a step-by-step process for getting FTC Live installed and the event ready.

Start with the :doc:`/ftc_live/setup/overview/overview` to learn how the three
systems fit together, what the scoring server is, and what is new this season.
Then work through the pages in this order:

#. :doc:`Hardware and Network Requirements </ftc_live/setup/hardware_and_network/hardware-and-network>`:
   what to bring and how to lay out the system.
#. :doc:`Install FTC Live and Log In </ftc_live/setup/install_and_login/install-and-login>`:
   download, install, and sign in.
#. :doc:`Transfer Event Data </ftc_live/setup/transfer_event_data/transfer-event-data>`:
   move the event from the Event Portal to FTC Live.
#. :doc:`Event Preparation </ftc_live/setup/event_preparation/event-preparation>`:
   check schedules and teams, print documents, and set up users, sponsors,
   and inspection.

When setup is done, continue to :doc:`/ftc_live/event_operation/index` to run
matches, alliance selection, playoffs, and awards. Optional and special-case
topics, such as audience displays, inspection tools, dual division events, and
paper scoring, are in :doc:`/ftc_live/features/index`.
