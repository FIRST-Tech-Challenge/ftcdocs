Scorekeeper
===========

The Scorekeeper is the :term:`volunteer <Volunteer>` responsible for running
the FTC Live scoring system at an event, in collaboration with the *FIRST*
Technical Advisor (FTA) and Technical Director. Documents in this section
help Scorekeepers, FTAs, and Technical Directors plan and run events.

- :doc:`FTC Live Setup Guide </ftc_live/setup/index>` - how to install, set up, and
  prepare the FTC Live scoring software for an event, step by step.
- :doc:`FTC Live Event Operation </ftc_live/event_operation/index>` - how to run
  matches, alliance selection, playoffs, and awards on event day.
- :doc:`FTC Live Features </ftc_live/features/index>` - optional and
  special-case features, such as audience displays, inspection tools, dual
  division events, and paper scoring.
