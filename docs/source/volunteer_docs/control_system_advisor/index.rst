Control System Advisor
======================

The Control System Advisor (CSA) is the :term:`volunteer <Volunteer>` who helps
teams with control system problems at a *FIRST* Tech Challenge event. The
documents in this section help CSAs prepare for and run their events.

- :doc:`Control System Troubleshooting Guide </control_system_troubleshooting/index>` -
  how to avoid, diagnose, and resolve common problems with the wireless
  Control System, for teams and for the technical volunteers who support
  them.
