Technical Director
==================

The Technical Director is the :term:`volunteer <Volunteer>` responsible for
the technical side of a *FIRST* Tech Challenge event. The documents in this
section help Technical Directors plan for and run their events.

- :doc:`Event Streaming Best Practices </event_streaming/index>` - how to
  put together a reliable livestream for an event, from a single-field
  qualifier up to a championship.
